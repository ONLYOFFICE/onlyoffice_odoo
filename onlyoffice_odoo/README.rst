Edit and collaborate on office files within Odoo using `ONLYOFFICE Docs`_.

This app integrates the ONLYOFFICE Docs editor directly into Odoo, enabling
users to create, edit, and co-author text documents, spreadsheets, and
presentations in any Odoo section where file attachments are available (Sales,
Discuss, Documents, CRM, and more).

Key features:

* Edit and view office files attached anywhere in Odoo (DOCX, XLSX, PPTX, PDF, and more)
* Real-time collaborative editing with Fast and Strict co-editing modes
* Track Changes, comments, and built-in chat
* JWT-secured communication between Odoo and ONLYOFFICE Docs
* Support for self-hosted and cloud ONLYOFFICE Docs instances
* Demo server available for evaluation

.. _ONLYOFFICE Docs: https://www.onlyoffice.com/docs-registration.aspx

Installation
============

This module requires the ``pyjwt`` Python package:

.. code-block:: bash

    pip install pyjwt

A running instance of `ONLYOFFICE Docs`_ is also required. It must be
reachable from both the Odoo server and the users' browsers, and must be
able to POST back to Odoo.

Installation options:

* **Self-hosted (free Community Edition)** — via `Docker`_ or manual install
* **Self-hosted (Enterprise Edition)** — scalable, professionally supported
* **Cloud** — `ONLYOFFICE Docs Cloud`_ (no installation required)

.. _ONLYOFFICE Docs: https://www.onlyoffice.com/download-docs.aspx
.. _Docker: https://github.com/onlyoffice/Docker-DocumentServer
.. _ONLYOFFICE Docs Cloud: https://www.onlyoffice.com/docs-registration.aspx

Configuration
=============

Go to **Settings → ONLYOFFICE** after installation.

Document Server URL
===================

Enter the public URL of your ONLYOFFICE Docs instance (e.g.
``https://documentserver.example.com/``).

JWT Security
============

JWT is enabled by default. A secret key is generated automatically to
restrict access to ONLYOFFICE Docs. To use a custom key, enter it in the
**Secret key** field and set the same key in your `ONLYOFFICE Docs
configuration file`_.

If the default ``Authorization`` JWT header conflicts with your setup,
change it to a custom value in the **JWT Header** field.

.. _ONLYOFFICE Docs configuration file: https://api.onlyoffice.com/docs/docs-api/additional-api/signature/

Network Configuration
=====================

If your Odoo and ONLYOFFICE Docs servers cannot reach each other via their
public addresses, fill in the following fields:

* **ONLYOFFICE Docs address for internal requests from the server** — the URL
  that Odoo uses to contact ONLYOFFICE Docs internally.
* **Server address for internal requests from ONLYOFFICE Docs** — the URL
  that ONLYOFFICE Docs uses to call back into Odoo.

Other Settings
==============

* **Open file in the same tab** — when checked, files open in the current
  browser tab instead of a new one.
* **Disable certificate verification** — use only for development/testing
  with self-signed certificates.
* **Demo server** — connect to the public ONLYOFFICE demo server for a
  30-day trial. Do not use with sensitive data.

Usage
=====

Once configured, click any supported office file attached to an Odoo record
to open it in the ONLYOFFICE editor.

The editor is available in all standard Odoo sections that support file
attachments: Sales, Discuss, CRM, Project, and others.

Supported formats for **editing**: DOCX, DOTX, DOCM, DOTM, XLSX, XLTX,
XLSM, XLTM, PPTX, POTX, PPTM, POTM, PDF.

Supported formats for **viewing only**: DOC, ODT, RTF, TXT, CSV, ODS, ODP,
PPT, and many more.

Multiple users can edit the same document simultaneously. Use the co-editing
mode (Fast or Strict), Track Changes, comments, and the built-in chat for
collaboration.
