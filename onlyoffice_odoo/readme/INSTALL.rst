This module requires the ``pyjwt`` Python package:

.. code-block:: bash

    pip install pyjwt

A running instance of `ONLYOFFICE Docs`_ is also required. It must be
reachable from both the Odoo server and the users' browsers, and must be
able to POST back to Odoo.

Installation options:

* **Self-hosted (free Community Edition)** — via `Docker`_ or manual install
* **Self-hosted (Enterprise Edition)** — scalable, professionally supported
* **Cloud** — `ONLYOFFICE Docs Cloud`_ (no installation required)

.. _ONLYOFFICE Docs: https://www.onlyoffice.com/download-docs.aspx
.. _Docker: https://github.com/onlyoffice/Docker-DocumentServer
.. _ONLYOFFICE Docs Cloud: https://www.onlyoffice.com/docs-registration.aspx
