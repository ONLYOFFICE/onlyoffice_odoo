Edit and collaborate on office files within Odoo using `ONLYOFFICE Docs`_.

This app integrates the ONLYOFFICE Docs editor directly into Odoo, enabling
users to create, edit, and co-author text documents, spreadsheets, and
presentations in any Odoo section where file attachments are available (Sales,
Discuss, Documents, CRM, and more).

Key features:

* Edit and view office files attached anywhere in Odoo (DOCX, XLSX, PPTX, PDF, and more)
* Real-time collaborative editing with Fast and Strict co-editing modes
* Track Changes, comments, and built-in chat
* JWT-secured communication between Odoo and ONLYOFFICE Docs
* Support for self-hosted and cloud ONLYOFFICE Docs instances
* Demo server available for evaluation

.. _ONLYOFFICE Docs: https://www.onlyoffice.com/docs-registration.aspx
